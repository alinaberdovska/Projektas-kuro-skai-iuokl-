# 🚗 Kuro Skaičiuoklė (Pirmas Projektas)

Moderni React aplikacija, skirta kuro sąnaudų, kelionės išlaidų skaičiavimui bei vartotojų paskyrų valdymui.

![Project Preview](https://via.placeholder.com/800x450.png?text=Kuro+Skaiciuokle+UI)

## 🚀 Technologijos

- **Framework:** [React](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** Pure CSS / Modern CSS Variables
- **Language:** JavaScript (ES6+)

## ✨ Funkcionalumas

- 🔐 **Autentifikacija:** Moderni prisijungimo / registracijos forma su el. pašto validacija.
- ⛽ **Kuro skaičiuoklė:** Kelionės kainos ir kuro sąnaudų skaičiavimai (vystoma).
- 🎨 **Modernus UI:** Tamsios/šviesios temos stilius, stiklo (*glassmorphism*) efektas bei responsyvus dizainas.

## 🛠️ Paleidimas vietoje (Local Setup)

1. Klonuokite repository:
   ```bash
   git clone https://github.com/your-username/pirmas-projektas.git
   ```

2. Įdiekite priklausomybes:
   ```bash
   npm install
   ```

3. Paleiskite vystymo serverį:
   ```bash
   npm run dev
   ```

4. Atidarykite naršyklėje: `http://localhost:5173`

---
*Mokomasis projektas sukurta naudojant React + Vite.*
